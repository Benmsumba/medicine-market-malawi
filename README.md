# Medicine Market Malawi

A fictional marketplace prototype for comparing medicine prices and reported availability. Run a static server from the project directory, for example `python -m http.server 8080`, and open localhost:8080.

Compare offers only within an exact catalogue product. An offer becomes unconfirmed after 24 hours. The pharmacy workspace edits demo records and keeps recent changes in browser storage.

Before a real pilot, add authenticated branch accounts, shared storage and server-side update history. Agree with participating pharmacies on catalogue mappings, branch contact details, and update responsibilities before publishing real listings. The current cities and listings illustrate the interface and do not represent a launch location or a participating pharmacy.
